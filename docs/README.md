# UniFi Manager — Documentación

Repositorio dedicado a la administración, configuración y monitoreo del switch UniFi US-8-60W y la integración con el UniFi Controller.

## Archivos Principales
- `docs/estado_switch_unifi.md`: Informe técnico del estado y configuración de puertos del switch.
- `docs/sw_casa_backup.json`: Respaldo estructurado de la configuración del switch.
- `/tools`: Herramientas de consulta y configuración (y enlaces a herramientas compartidas).
